HLZF 隐私政策

更新日期：2026年9月22日 · 生效日期：2026年9月22日

HLZF 是一款家庭生活管理工具。当前版本无需注册登录，家庭记录保存在本机，不自动上传；用户协议和隐私政策可离线阅读。

一、适用范围与运营主体

本政策适用于武汉市浩长飒科技有限公司提供的 HLZF Android 应用，说明家务事项、家庭用品、生活计划、周期例行、每周回顾和手动备份功能中的数据处理方式。

二、我们处理哪些数据

  • 家庭记录：你输入的事项标题、备注、所属空间、标签、用品数量与单位、补货阈值、计划日期与检查点、例行频率及打卡记录，用于展示、编辑和计算本地进度。这些内容保存在应用本地存储中，不自动发送给我们。
  • 本地设置：应用在本机保存协议同意状态、默认家庭空间及入门模板初始化状态。首次进入时会加入默认空间和示例内容，可在应用中编辑或删除，后续启动不重复添加。
  • 手动备份：你主动导入或导出时，应用通过 Android 系统文件选择器读取或写入你指定的 JSON 文件，文件包含家庭空间、事项、计划、例行及相关记录。导入替换现有记录前会要求确认。
  • 支持邮件：仅当你在外部邮件应用中确认发送后，我们才会收到你的邮箱地址、邮件内容及你自行附加的资料，并用于处理建议、咨询或数据请求。应用不会自动附加家庭记录、设备信息或日志。请勿发送与问题无关的敏感信息。

三、权限、联网与第三方服务

应用声明了网络访问权限，具备联网能力；当前家庭记录功能仍在本地运行，不会自动上传家庭记录。当前版本不申请通讯录、定位、相机、麦克风、通知或广泛存储访问权限；不接入广告、用户统计、社交登录或设备标识采集 SDK，不主动采集 IMEI、IMSI、Android ID、OAID、广告标识符、MAC 地址或设备序列号。

应用使用 AndroidX/Compose 提供界面与本地功能，使用 Gson 处理本地 JSON 数据，不利用这些组件向我们上传家庭记录。备份只访问你在系统文件选择器中指定的文件，无需授予整个存储空间的访问权限。

如果你选择云盘作为备份位置，或使用邮件应用发送反馈，相应云盘或邮件服务可能联网并处理所选文件或邮件，其处理方式适用该服务自己的政策；这由你的操作触发，并非 HLZF 自动上传。

四、保存、安全与删除

家庭记录保存在设备的应用专属存储内，直至你删除记录、清空业务数据、清除应用数据或卸载应用。应用关闭了 Android 自动云备份；系统或设备厂商提供的迁移能力由相应系统管理。

导出的 JSON 备份未加密。请保存在可信位置，不要随意分享。卸载应用或清空本地记录不会删除你已经导出的文件或外部服务中的副本，你需要在相应位置自行删除。设备丢失、损坏、误删除或导入覆盖可能造成记录丢失，请提前备份。

对于主动发来的支持邮件，我们仅在处理请求所需期间及适用法律要求的期限内保存；你可以通过联系邮箱提出查询、更正或删除请求。我们无法远程读取或替你恢复仅保存在设备上的家庭记录。

五、共享与披露

我们不出售你的家庭记录，也不将本地家庭记录提供给广告或统计服务。你主动选择导出、分享备份或发送邮件时，请确认接收方与内容。对我们收到的支持信息，如依法必须向有权机关提供，将按适用要求处理。

六、你的选择和权利

  • 无需创建账号，因此没有账号注销流程；停止使用可卸载应用。
  • 可在对应页面查看、修改或删除事项、计划和例行，在“设置”页导出备份或选择“清空全部家庭记录”删除业务记录。
  • “清理缓存”仅处理临时文件，不等于删除家庭记录。彻底清除应用设置和协议同意状态，可使用系统设置中的清除应用数据。
  • 首次使用可选择不同意协议并退出。更新本政策后，如涉及需要重新取得同意的变更，将通过应用内提示说明并请求确认。

七、未成年人

未成年人应在监护人指导下阅读本政策和使用本应用。请勿在家庭记录或反馈中填写不必要的身份、健康、财产等敏感信息。监护人可通过下方方式联系我们处理相关请求。

八、政策更新

本政策依据当前版本实际功能编写。增加联网、账号或第三方数据处理功能时，我们将相应更新说明，并在需要时先取得你的同意。你可在设置中随时查看本政策。
